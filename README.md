📖 About the Project

AdoptiPet is a mobile application built as part of a university project, designed to bridge the gap between animal shelters and people looking to adopt. The app brings together animal listings, shelter directories, adoption tracking, donations, and a pet product marketplace — all in one clean, easy-to-use experience.

Built and prototyped end-to-end in FlutterFlow.

✨ Features
Feature	Description
🐶 Browse Animals	Search and filter through a list of adoptable animals
📍 Shelter Directory	Discover nearby shelters with full details and addresses
❤️ Adoption Follow-Up	Track the progress and well-being of your adopted companions
💰 Donations	Support shelters directly with a live funding-progress system
🛒 Pet Product Marketplace	Browse and manage pet food, supplies, and essentials
✍️ Shelter Management Tools	Add, edit, and remove animal or shelter listings with ease
🔐 Authentication	Secure sign-up and login for adopters and shelter admins
